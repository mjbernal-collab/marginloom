# Marginloom on your phone

Phone address: https://marginloom.agilemelon4.chatgpt.site

The hosted copy is private. Sign in with the ChatGPT account that owns this site on your first visit. The address serves the app files; your uploaded notes and AI inference stay on your device.

## Install

1. Open the address while connected to the internet.
2. **Android:** use Chrome, then its menu → **Install app** or **Add to Home screen**.
3. **iPhone:** use Safari → **Share** → **Add to Home Screen**. Enable **Open as Web App** if shown.
4. Open Marginloom from its new home-screen icon. Let the app finish its initial loading before testing offline.

This is an installed web app, so you do not need an APK or App Store download. Your PC does not need to stay running for this hosted copy.

## Transfer your material

On the PC, use **Settings & offline setup** to export a backup. Send that JSON file to your phone and restore it from the same settings screen in the installed phone app. The hosted address, localhost address, and Windows app each have separate storage.

AI model files are not included in the backup. Set them up separately on the phone while online. Try the Compact profile first; availability depends on your phone's WebGPU support and memory. Detailed AI and natural speech can use substantial memory and storage. Source search and saved study activities remain useful on devices that cannot run the language model.

## Test offline before relying on it

Finish installation and any optional model downloads, close the app, enable airplane mode, then reopen it using the home-screen icon. Check saved materials and activities. If you installed local AI, also test a new question. Downloading files and loading cached files are different operations; an offline reload can read saved files without a network download.

Desktop browser checks verify the responsive layout and cached app behavior. Physical Android and iPhone installation, storage retention, and model performance still need testing on your devices. Keep a backup: browsers and operating systems can clear local storage under storage pressure.
